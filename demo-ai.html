🚀 Quick Start Guide

1. Install Dependencies

First, install the required Node.js packages:

# Navigate to project directory cd shopper-copilot # Install dependencies npm install

2. Start the Backend Server

The backend server handles OpenAI API calls securely:

# Start the server (runs on port 3000) npm start # You should see: ╔════════════════════════════════════════════════════╗ ║ 🛍️ Shopper Copilot Backend Server ║ ║ Status: Running ║ ║ Port: 3000 ║ ╚════════════════════════════════════════════════════╝

3. Test the AI Features

Try these AI-powered features in the chat widget (bottom-right):

💬 Smart Chat

Ask questions about products and get intelligent responses from GPT

📝 AI Summary

Click "AI Summary" to get a comprehensive page analysis

🔗 Link Analysis

AI identifies and ranks the most important links

📤 Smart Sharing

AI generates friendly messages to share with friends

✅ Server Status

⏳ Checking backend connection...

🔑 API Key Configuration

Your OpenAI API key is securely stored in .env file (never in client code!):

# .env file (automatically configured) OPENAI_API_KEY=sk-proj-HR6l... PORT=3000 NODE_ENV=development

💡 Tips

  • Keep the backend server running in a separate terminal
  • The widget will show "Online - AI Ready" when connected
  • If offline, check that server is running on port 3000
  • API usage is tracked - check your OpenAI dashboard
